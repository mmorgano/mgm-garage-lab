An independent software lab exploring developer tooling, AI-assisted engineering and data systems.

- [About](https://mgmgaragelab.com/about/)
- [Workflow Management](https://mgmgaragelab.com/workflow-management/)

## Local preview

Serve this directory with any static web server. The homepage is `index.html`
and the internal pages live in `projects/`, `notes/`, `about/` and
`workflow-management/`.

## Publishing

The site uses the repository root on GitHub Pages. Keep `CNAME` unchanged.
No build step or external package dependency is required.

Publish `docs/workflow-management-overview.pdf` in the Workflow Management
repository before publishing this website update. The landing page links to
that canonical PDF so it does not need a second copy here.
