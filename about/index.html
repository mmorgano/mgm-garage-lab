About the lab

A small place for building software in public.

MGM Garage Lab is the independent engineering lab of Maurizio Morgano: a place to build, test and document personal software projects with clear boundaries between public open-source work, experiments and private research.

01 / Position

The lab is not trying to look like a startup.

It is a portfolio of engineering practice: small tools, focused experiments and notes about the decisions behind them. Mature projects can be shown as case studies. Early projects can stay visibly early.

Built in the open

When a project is clean, independent and useful, the code and reasoning can be shared publicly.

Boundaries matter

Professional and client-derived work is not reproduced here. The site demonstrates capability through independent projects.

Honest maturity

Projects carry status labels so experiments do not have to pretend to be production products.

02 / Contact

Follow the work where the code lives.
